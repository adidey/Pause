Refine the existing “Worth It?” mobile app UI. Do NOT redesign the app from scratch. Preserve the existing visual identity, typography direction, navigation structure, content hierarchy and overall concept, but significantly improve the visual polish, hierarchy, card presentation, gradients, context screen and insights/habits experience.

1. Overall visual direction

The app should feel like a premium, editorial, slightly experimental lifestyle/finance app rather than a conventional budgeting app.

Keep:

The bold oversized typography.
The clean geometric sans-serif font system.
Strong black typography against very light backgrounds.
Generous whitespace.
Rounded surfaces.
Small uppercase monospaced labels for metadata.
Minimal navigation.
Soft pastel colour atmosphere.

The visual inspiration should be closer to modern editorial/mobile art direction, with typography and objects doing most of the visual work. Avoid generic SaaS dashboards, generic fintech cards, excessive gradients, excessive shadows or overly colourful UI.

The interface should feel calm, tactile, intelligent and desirable.

2. Typography corrections

Keep the existing font system and bold typographic character, but improve consistency.

Use one strong display sans-serif for major headings.
Use the same family consistently throughout the interface.
Large headings should feel intentionally oversized rather than simply large.
Fix awkward line breaks such as “WORTH / IT?” when they aren't intentional.
Keep display headings tight and bold.
Use medium/regular weights for supporting copy.
Use monospaced uppercase typography for small metadata labels such as:
HOBBIES, WAITING, 3 ON YOUR MIND, SPENDING, CONTEXT.
Reduce unnecessary font-weight variation.
Improve baseline alignment between numbers, units and labels.
Make dollar amounts visually dominant but not so large that they overwhelm the actual object name.
Ensure every screen has a clear typographic hierarchy: eyebrow → headline → supporting text → content → action.
3. Replace the current blue gradient treatment

The current blue/purple gradient feels too uniform and slightly artificial.

Replace it with a much softer, atmospheric pastel gradient system.

Use subtle combinations of:

powder blue
lavender
very pale lilac
warm ivory
extremely soft peach
muted periwinkle

Avoid saturated electric blue.

The gradient should feel almost like light moving across paper or frosted glass, rather than a colourful background.

Use gradients selectively:

Home can have a very subtle atmospheric background.
Contexts can use more expressive colour.
Insights can use a calmer variation.
Detail/action screens should remain mostly pale and neutral.

The background should never compete with the typography.

4. HOME / WANTS SCREEN — make it much more powerful

The current home screen feels too much like a list of ordinary cards.

Transform the main purchase presentation into a visual “want ticket / shopping-list object” system.

Each want should feel like something the user has physically saved for later.

Instead of a generic rectangular financial card, create a more distinctive object-based card inspired by:

shopping tickets
boarding passes
collectible cards
editorial product cards
physical receipts

Do NOT literally copy any reference design.

Each want card should contain:

Product image / visual

Add a prominent product image area or image placeholder.
The image should make the item immediately recognisable.
Allow product imagery to visually overlap or extend slightly outside the card.
Use rounded image cropping.

Product information

The price should remain the dominant numerical element.

6. “In Your World” / Context screen

Keep the concept of contexts, but improve the visualisation.

The current spatial map is interesting but feels slightly like coloured blobs placed behind labels.

Make it feel more intentional and alive.

Keep contexts such as:

HOBBIES
HOME
FITNESS
TRAVEL
STUDY
WORK
PERSONAL

Use soft pastel atmospheric colour fields, but:

Give each context a distinct but harmonious pastel tone.
Avoid overly saturated colours.
Allow colour fields to softly overlap.
Make larger contexts visually more prominent.
Make the size of a context represent the relative number of wants.
Use subtle movement/flow in the composition.
Labels should remain extremely clean and readable.
Avoid making it look like a conventional bubble chart.

Think of it as a personal map of desire, not a data visualisation.

Consider using subtle connecting lines, halos, orbital relationships or layered translucent shapes where useful.

The user should immediately understand:

“These are the areas of my life where my wants are accumulating.”

Tapping a context should reveal its wants.

8. WAIT screen

Keep the strong giant:

WAIT

But make the screen feel more emotionally persuasive.

The key idea is:

“You still want this. You simply don't need to decide today.”

Keep the three choices:

Wait 7 days

Buy it anyway

Skip it

Make “Wait 7 days” the obvious primary action.

Make “Buy it anyway” secondary.

Make “Skip it” quiet and low emphasis.

Consider a subtle countdown/progress indicator showing the waiting period.

The product card should retain its image and comparison information.

12. Design system

Establish reusable components and tokens for:

typography
spacing
corner radius
pastel backgrounds
status pills
comparison chips
want cards
product image containers
primary/secondary buttons
bottom navigation

Use consistent spacing and corner radii throughout.

Avoid excessive shadows. Prefer soft tonal separation, translucency and subtle borders.

13. Most important design principle

Do not make this look like a budgeting app.

“Worth It?” is about the psychology of wanting something.

The UI should make the user feel like they are looking at their desires from a small distance, rather than managing their finances.

The product should feel:

editorial + tactile + calm + slightly playful + premium + introspective

The strongest visual element should be the thing the user wants, not the financial statistics.

Product imagery + typography + whitespace should create the visual personality.

Use the pastel gradients as atmosphere, not decoration.

Keep the UI highly usable and accessible despite the experimental visual direction.
