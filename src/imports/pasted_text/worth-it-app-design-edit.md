EDIT THE EXISTING “WORTH IT?” APP DESIGN — DO NOT REBUILD THE APP FROM SCRATCH.

Keep the existing overall concept, navigation, typography direction, rounded cards, pastel aesthetic, and minimalist editorial feel. The goal is to refine the current design into a more polished, cohesive, premium mobile experience.

IMPORTANT:
Preserve the existing information architecture and functionality. Focus on visual refinement, spacing, hierarchy, responsiveness, component consistency, and interaction details.

━━━━━━━━━━━━━━━━━━━━━━
1. GLOBAL VISUAL SYSTEM
━━━━━━━━━━━━━━━━━━━━━━

Create one cohesive visual language across every screen.

The current screens use slightly different pastel gradients. Unify them into a consistent “Worth It?” gradient system rather than having each page feel like it belongs to a different app.

Use:
- soft pastel lavender
- powder blue
- pale peach
- warm cream
- subtle mint
- very soft pink

The gradients should feel:
- airy
- slightly 3D
- diffused
- atmospheric
- premium
- almost like coloured light floating behind frosted glass

Avoid harsh colour transitions, saturated rainbow gradients, or obvious linear gradients.

Prefer large blurred radial/mesh-style gradients with multiple subtle colour fields.

Use the gradient primarily as a background atmosphere. Cards should remain highly readable.

Maintain:
- near-black typography
- muted lavender/grey secondary text
- white/off-white cards
- large rounded corners
- subtle borders
- very soft shadows
- generous whitespace

Do not introduce lots of colours or decorative UI elements.

banking app
corporate dashboard
generic AI app

The emotional feeling should be:

“Before I buy something, I pause and see what it means in my world.”

Maintain the current strong typography and minimalist black/white foundation, but elevate the visual system through:
- better gradients
- stronger branding
- improved safe-area spacing
- collectible ticket cards
- product imagery
- subtle 3D atmospheric backgrounds
- meaningful infographics

- responsive layouts
- tactile motion

Do not overcrowd the UI.

Prioritize hierarchy, whitespace, typography and interaction over decoration.
